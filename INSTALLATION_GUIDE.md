# Gesture Drive 3D — Installation Guide

## System Requirements

- **OS:** Windows 10 or Windows 11 (64-bit)
- **RAM:** 4 GB minimum, 8 GB recommended
- **Storage:** 500 MB free space
- **Webcam:** Optional — required for hand gesture controls
- **Internet:** Optional — required for AI styling assistance

## Installation

1. Download `Gesture Drive 3D Setup 0.2.0.exe` from the release page.
2. Run the installer.
3. Choose installation directory (default: `C:\Users\<User>\AppData\Local\Programs\Gesture Drive 3D`).
4. Follow the installation wizard.
5. Launch Gesture Drive 3D from the desktop shortcut or Start menu.

## First Launch

1. The application opens to the vehicle selection screen.
2. Select **BMW M4 G82** from the catalogue (the only verified available model).
3. Click **Load** to load the real 3D model.
4. The vehicle appears in the 3D showroom.

## Webcam Setup (Optional)

1. Connect a USB webcam.
2. Click the camera icon in the top bar.
3. Allow camera permission when Windows prompts.
4. The gesture panel appears in the bottom-right.
5. Calibrate by holding one hand steady in view.

## AI Styling Setup (Optional)

1. Set environment variable `OPENAI_API_KEY` or `ANTHROPIC_API_KEY`.
2. Restart the application.
3. Open the AI Assistant panel.
4. Type a styling request (e.g., "Make it racing red").
5. Preview and apply the suggestion.

## Offline Mode

All core features work offline:
- Vehicle loading and inspection
- Paint and material customization
- Project save/load
- Gesture controls (with webcam)
- Offline styling presets

## Uninstallation

1. Open **Settings → Apps → Installed apps**.
2. Find **Gesture Drive 3D**.
3. Click **Uninstall**.
4. Follow the uninstaller prompts.

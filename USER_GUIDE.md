# Gesture Drive 3D — User Guide

## Overview

Gesture Drive 3D is a premium automotive digital customization studio. Select a vehicle, customize its appearance with paint and materials, use hand gestures to interact with the 3D model, and get AI-powered styling suggestions.

## Vehicle Selection

1. Open the **Library** tab on the left.
2. Browse manufacturers: BMW, Mercedes-Benz, Audi, Porsche, Tata Motors, Mahindra.
3. Select a model (only BMW M4 G82 is currently available as a verified real asset).
4. Click **Load** to load the 3D model.

## 3D Showroom Controls

| Action | Mouse | Gesture |
|--------|-------|---------|
| Rotate | Click + drag | Open palm + move |
| Zoom | Scroll wheel | Pinch (one hand) |
| Select component | Click on part | Point + dwell 700ms |
| Exploded view | Slider in right panel | Two hands spread |
| Reset view | Press `R` | — |

## Customization

### Paint
1. Select the **Exterior** category.
2. Choose a paint preset or use the color picker.
3. Adjust metallic, roughness, and clearcoat sliders.
4. Click **Apply to Body**.

### Component Materials
1. Click a component in the 3D view (e.g., body, wheels).
2. The right panel shows component details.
3. Adjust material properties.
4. Click **Apply to Part**.

### Replacement Parts
1. Open the **Parts** tab.
2. Import a GLB/glTF replacement part.
3. Select the component to replace.
4. Click **Install**.

## Gesture Controls

| Gesture | Action |
|---------|--------|
| Pinch | Zoom in/out |
| Open palm | Rotate view |
| Point + dwell | Select component |
| Two-hand spread | Exploded view |
| Two-hand pinch | Zoom (if enabled) |
| Thumbs up | Confirm customization |
| Closed fist | Pause interaction |

## AI Styling Assistant

1. Open the **AI Assistant** panel.
2. Type a request (e.g., "Make it luxury black").
3. Preview the suggestion.
4. Click **Apply** or **Cancel**.
5. Use **Undo** to revert.

## Project Save/Load

- **Save:** Click the save icon or go to **File → Save Project**.
- **Open:** Click **Open saved design** in the Library tab.
- Projects preserve vehicle identity, paint, materials, and replacement parts.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |
| `Ctrl+S` | Save |
| `R` | Reset camera |
| `Esc` | Cancel preview / close panel |

## Tips

- The 3D viewport is the primary interaction area — avoid covering it with panels.
- Use **high** quality for best visuals; **low** for better performance.
- Gesture calibration improves tracking accuracy.
- AI features require an API key; offline presets work without credentials.
